ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ

1. ОБЩИЕ ПОЛОЖЕНИЯ

Настоящая Политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей Telegram-бота @The_Riffa_bot.

2. КАКИЕ ДАННЫЕ МЫ СОБИРАЕМ

2.1. Мы собираем следующие данные:
- Telegram ID пользователя
- Username (если указан)
- Email (если пользователь предоставил)
- История генераций музыки
- Данные об использовании промокодов
- Реферальная информация

2.2. Мы НЕ собираем:
- Номера телефонов
- Данные банковских карт (обрабатываются платёжной системой)
- Личные сообщения

3. КАК МЫ ИСПОЛЬЗУЕМ ДАННЫЕ

3.1. Персональные данные используются для:
- Предоставления услуг по генерации музыки
- Обработки платежей
- Технической поддержки
- Улучшения качества сервиса

3.2. Мы не передаём ваши данные третьим лицам, за исключением:
- Платёжных систем FreeKassa и Robokassa (для обработки платежей)
- По требованию государственных органов

4. ЗАЩИТА ДАННЫХ

4.1. Мы используем технические и организационные меры для защиты данных:
- Шифрование соединений (SSL/TLS)
- Ограниченный доступ к базе данных
- Регулярное резервное копирование

5. ВАШИ ПРАВА

5.1. Вы имеете право:
- Запросить удаление своих данных
- Получить копию своих данных
- Отозвать согласие на обработку данных
