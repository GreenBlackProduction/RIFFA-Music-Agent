## 1. Что уже выяснено (архитектура — карта)
- **Endpoint:** `backend/app/api/v1/agent.py` — `AsyncOpenAI` chat-completion, модель выбирается `_pick_model()` (gpt-4o ↔ gpt-4o-mini, ~line 1231). **Tools/function-calling НЕ используются.**
- **Системный промпт:** ~500 строк (внутри agent.py, ~171–647). Содержит: FAST PATH по референсу (215–263), CONFABULATION GUARD (380), MODULE ROUTER (428), требования к `research_notes`/`music_params`.
- **Референсы:** `backend/app/services/track_reference.py` — `detect_reference_url` + `resolve_reference` ищут только **URL** (Spotify/YouTube/Deezer-ссылка) через **Deezer API** (BPM, эра, название). **Имя исполнителя текстом не резолвится.**
- **Downstream:** `lyrics.py`, `prompt_engineering.py` строят финальный Suno-промпт из `music_params` + `research_notes`. Жёсткое правило: имена артистов вырезаются (`strip_artist_references`), Suno их реджектит.
- **Фронт:** `frontend/src/components/studio/AgentChat.tsx` — чат + wizard (slots genre/mood/tempo/vocal), `chips.tempoLabel` и т.п.
- **Память:** `project_riffa_agent_tags.md` — выбрана Last.fm `getTopTags`, нужен `LASTFM_API_KEY` + интеграция (PENDING).

## 2. Корневая гипотеза бага (проверить)
Пользователь ввёл **имя исполнителя** (не ссылку) как референс →
`detect_reference_url` ничего не нашёл (нет URL) → **поиск не запущен** →
gpt-4o опирается только на свои знания → на нишевом/региональном артисте
**конфабулирует** (берёт не того) → FAST PATH (215) велит «не задавать вопросы,
строить бриф немедленно» → агент **застревает** на ошибочном артисте.
CONFABULATION GUARD (380) не сработал/проигнорирован.

## 5. Предложения по улучшению (черновик — обсудить с owner)
1. **Реальное заземление по ИМЕНИ артиста (главное):** добавить `search_artist(name)` —
   - быстрый путь: **Deezer artist search** (клиент уже есть в `track_reference.py`) → жанры/похожие/топ-треки → эра/BPM;
   - либо **Last.fm `getTopTags`** (как в памяти; нужен `LASTFM_API_KEY`).
   Результат поиска кладём в `research_notes` ВМЕСТО догадок. Нет совпадения → честно сказать и переспросить.
2. **Tools / function-calling:** дать модели инструмент `search_artist`, чтобы она сама вызывала поиск, когда не уверена (вместо «знаю/не знаю» в промпте).
3. **Ужесточить CONFABULATION GUARD:** при низкой уверенности И отсутствии хита поиска — НЕ строить бриф (`done=false`), а спросить/предложить варианты. Сейчас FAST PATH слишком рано коммитит.
4. **Скорость/стоимость:** урезать системный промпт (500 строк → вынести примеры/правила в компактные секции), кэшировать статичную часть, пересмотреть `_pick_model`.
5. **UX смены референса:** явная кнопка/команда «сменить референс» в `AgentChat.tsx`, чтобы не приходилось «уговаривать» агента.
6. **Наблюдаемость:** логировать на турн — модель, латентность, был ли поиск, уверенность, финальные params; для регресс-тестов.

# Part B — корректность генерации (вокал, типы/модели, обложки)

> тип генерации, модель и ключевые ограничения (вокал/текст), во всех случаях.

## 7. Жёстко указывать ВОКАЛ / ИНСТРУМЕНТАЛ в промте
- **Баг:** заказан инструментал → пришло 2 версии, одна **с вокалом**. В промте не было явного «без вокала».
- **Где:** `frontend/src/pages/StudioPage.tsx` `buildPrompt` (~430 `Vocal type:`); `backend/app/services/lyrics.py` / `prompt_engineering.py` (финальный Suno-промпт); флаг `instrumental` в Suno-запросе — `backend/app/services/suno.py` + `app/tasks/__init__.py`.
- **Фикс:** для instrumental / «без вокала» — ЖЁСТКО писать в промт `instrumental, no vocals` И выставлять Suno-флаг `instrumental: true` (проверить, что флаг реально уходит — баг скорее всего тут). Для модулей где вокала быть не должно (sound_effect; cover при instrumental) — аналогично. Where vocals ARE wanted — тоже явно. Агент (system prompt/coercion) должен прокидывать это ограничение в бриф.

## 8. Сообщение «Итоговый prompt» — правильный тип/модель
- **Баг:** при генерации ОБЛОЖКИ показалось «То, что отправится в **Suno / SFX API**». Должно быть про nano-banana (image-модель).
- **Где:** i18n `frontend/src/lib/i18n/locales/ru.ts:459-460` (`label: "Итоговый prompt"`, `desc: "То, что отправится в Suno / SFX API"`) и `en.ts:455`. Хардкод для всех модулей.
- **Фикс:** label/desc динамически по модулю — «Suno · музыка» / «Suno · SFX» / «Nano-Banana · обложка», + показывать вводные (модель, size). Чётко и ВСЕГДА, во всех сообщениях о запуске.

## 9. Прогресс-бар — актуальный тип/модель
- **Баг:** всегда «Suno создаёт музыку», даже для обложки.
- **Где:** `frontend/src/components/layout/ActiveGenerations.tsx` (статусы submitting/queued/generating + тексты).
- **Фикс:** статус по типу генерации: «Suno создаёт музыку» / «…SFX» / «Nano-Banana создаёт обложку». Завязать на `gen.type`.

## 10. Разрешение обложки (1024×1024 → выше?)
- **Где:** `backend/app/services/nanobanana.py:33` `size="1024x1024"`; модели `nano-banana / nano-banana-2 / nano-banana-pro`.
- **Задача:** выяснить, поддерживает ли nano-banana(-pro) `2048×2048`/больше (API APIYI `base_url https://api.apiyi.com/v1`). Если да — опция бОльшего размера (возможно только на pro-моделях). Если нет — задокументировать предел.

## 11. «Улучшить качество» (Enhance Pro) — меняет картинку
- **Баг:** улучшение кота → ДРУГОЙ кот + текст как у книжной обложки. Меняет композицию/персонажа, добавляет текст.
- **Где:** `frontend/src/components/studio/FileActions.tsx:263` `prompt: "enhance and upscale: {title}"` — слишком общий промт.
- **Фикс:**
  1. **Зашивать в запись генерации** (`generations.params`/`result`): исходный image-промт + флаг «нужен текст / без текста» + «vinyl cover, 1:1, без упаковочных/mockup-текстур».
  2. Enhance переиспользует исходные данные и инструктирует мощную модель: **сохранить композицию и персонажа**, улучшить только стиль/детали/художественность (без фанатизма), НЕ добавлять текст если не просили.
  3. Базовый промт обложки всегда: `vinyl cover art, square 1:1, no packaging/mockup, [text: "…" | no text]`. Детально про размещение текста.

## 12. Обложки НЕ в «последних треках»
- **Баг:** cover_art показываются в поле «последние треки» на студии.
- **Где:** `frontend/src/pages/StudioPage.tsx` `RecentTracks` (`recent = items.slice(0, 8)`).
- **Фикс:** фильтровать `item.type !== "cover_art"` (обложки — не треки). Проверить, нужно ли то же в других «последних» лентах.
